# fieldtime

Field encode/decode helpers for time payloads in pipelines.

**Site:** https://theworker02.github.io/fieldtime/

## Install / run

```bash
git clone https://github.com/theworker02/fieldtime.git
cd fieldtime
node src/cli.js
node --test
```
